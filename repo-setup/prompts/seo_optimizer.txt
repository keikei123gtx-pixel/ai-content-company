## SEO最適化チェックリスト
投稿前に必ず以下を確認してください。

### タイトルチェック
- [ ] 主要キーワードがタイトル前半にある
- [ ] 50文字以内（スマホで切れない）
- [ ] 感情語・具体語が入っている
- [ ] 競合と差別化できている

### サムネイルチェック
- [ ] 1280×720px
- [ ] テキストが大きく読める
- [ ] スマホの小サムネでも目立つ色使い
- [ ] タイトルとの関連性がある

### 説明欄チェック
- [ ] 最初の2行にキーワードあり
- [ ] チャンネル登録の呼びかけあり
- [ ] ハッシュタグ15〜20個
- [ ] タイムスタンプあり（1時間以上の動画）

### タグチェック
- [ ] 500文字以内
- [ ] 広いタグ→狭いタグの順
- [ ] 日本語・英語混在
- [ ] ブランドタグ（チャンネル名）を最後に
